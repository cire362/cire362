## 🚀 Проекты

**[ijs](https://github.com/cire362/ijs)** — платформа для застройщиков и агентов недвижимости, сделана под заказ целиком. Express, PostgreSQL, Socket.io, Vue 3 и Tailwind: 58 эндпоинтов REST API, авторизация на refresh-токенах с CSRF-защитой, чаты и уведомления в реальном времени, 40 интеграционных тестов, деплой в Docker с автоматическим HTTPS.

**[Self-service-terminal](https://github.com/cire362/Self-service-terminal)** — терминал заказа для ресторанов. Vue 3 и Pinia: экран гостя для планшета, панель персонала с заказами и управлением меню, интеграция с системой учёта iiko, обновления в реальном времени по нескольким WebSocket-каналам.

**[tracker-app-server](https://github.com/cire362/tracker-app-server)** и **[tracker-app-frontend](https://github.com/cire362/tracker-app-frontend)** — платформа для отслеживания прогресса в обучении с геймификацией. REST API из 95 эндпоинтов с документацией в Swagger, движок уровней и достижений, чат и система друзей на Socket.io, клиент на React и Material UI с локализацией.

**Solder** — экспериментальная нативная IDE для fullstack-команд на Rust с интерфейсом, отрисованным на GPU (GPUI): около 77 тысяч строк в 12 крейтах, 306 юнит-тестов и сайт на Next.js. Подсветка на tree-sitter, языковые серверы, расширения из каталогов Zed и VS Code, плагины как программы WebAssembly и WASI с моделью разрешений. Большая часть кода написана кодинг-агентами под моим руководством: я задаю архитектуру, ограничения и критерии готовности, проверяю каждый дифф, а правила для агентов лежат в `AGENTS.md`. Репозиторий пока приватный, готов показать и разобрать его лично.

**[discord_clone](https://github.com/cire362/discord_clone)** — десктопный мессенджер. Tauri и React на клиенте, Hono, Prisma и PostgreSQL на сервере: аутентификация на JWT, друзья, личные сообщения.
